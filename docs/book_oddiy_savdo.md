# Книга «Oddiy savdo kitobi»: выжимка

Книга на узбекском, для начинающих: классический ретейл-теханализ. Источник — выжимка Абу.

> **Главное правило для ассистента.** По Mr. Casino всё из этой книги — «Main Retail Focus»: эти паттерны = карта стопов (ликвидности), а не сигнал входа. Если сигнал из книги совпадает с FU / HCS — использовать его как цель или ликвидность, а не как вход. См. `strategy_mr_casino.md`, разделы 3 и 9.

## 1. Психология

- **FOMO** — вход на хаях или продажа на лоях из страха упустить движение.
- Против FOMO:
  - проверять источники;
  - иметь чек-лист стратегии;
  - помнить, что рынок цикличен;
  - принимать убытки.

## 2. Свечи

| Группа | Модели |
| --- | --- |
| Бычьи | Hammer / молот (длинная нижняя тень у поддержки; подтверждение — следующая зелёная свеча), Morning Star / утренняя звезда (3 свечи), Bullish Engulfing / бычье поглощение, Three White Soldiers / три белых солдата |
| Медвежьи | Hanging Man / повешенный, Shooting Star / падающая звезда, Bearish Engulfing / медвежье поглощение, Evening Star / вечерняя звезда, Three Black Crows / три чёрные вороны |
| Нейтральные | Doji, Spinning Top / волчок — нерешительность, входить через несколько свечей |

## 3. Термины

Entry (вход), Target (цель), Stoploss (стоп), Retest (ретест), R:R 1:3 (риск к прибыли).

## 4. Семь стратегий

Общее правило книги:

- НЕ входить на пробое трендовой линии.
- Ждать ретест + свечу в сторону движения либо пробой предыдущего хая / лоя.
- SL — за предыдущим экстремумом.

Паттерны:

1. Отбой от трендовой линии.
2. Симметричный треугольник.
3. Клин.
4. Медвежий флаг.
5. Бычий флаг.
6. Консолидация (пробой S/R + ретест).

## 5. Фигуры

Двойная вершина / двойное дно; тройная вершина / дно; голова и плечи (и обратная); клинья; флаги; прямоугольники; ромб; закруглённые вершина / дно; чашка с ручкой; Bat.

## 6. Как это использует ассистент

| Что в книге | Как читает ассистент по Mr. Casino |
| --- | --- |
| Свечная модель у зоны (молот, поглощение, звёзды, 3 солдата / вороны, повешенный) | Подтверждение манипуляции в зоне, если совпала с FU / HCS; сама по себе — не вход |
| Doji, волчок | «Ждать», а не входить; хай и лой Doji — major-ликвидность (если это не AFU) |
| Фигура (двойная вершина, клин, флаг, голова-плечи и т.д.) | Где стоят стопы толпы: цель и ликвидность |
| Трендовая линия | Ликвидность; идеальная (3+ касания) — major, неидеальная — minor |
| Пробой линии + ретест (вход по книге) | Не рекомендовать как вход; показать, где за ним лежат стопы |
| FOMO, чек-лист, принятие убытков | Спокойное напоминание, когда Абу хочет «догнать» рынок или торгует после серии стопов |
